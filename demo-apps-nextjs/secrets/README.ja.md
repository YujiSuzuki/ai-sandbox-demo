# secrets ディレクトリ

このディレクトリには、AI アシスタントから見えないようにすべき機密情報が含まれています。

## ファイル

- `demo-secret.key` - `/api/health` ルートハンドラが読み込むダミーの秘密情報

## セキュリティデモ

AI サンドボックス環境（DevContainer または cli_claude）で動作している場合：
- このディレクトリは空の tmpfs ボリュームとしてマウントされます
- AI アシスタントはこれらのファイルを読み取れません
- 一方、Next.js コンテナはアクセス可能です

フロントエンドとバックエンドが1プロセスに同居する Next.js のような
フレームワークでも、サーバー側のシークレットを AI コンテナから隠す必要が
あることを示すデモです。web/api を分割した構成での同等デモは
[demo-apps/securenote-api/secrets](../../demo-apps/securenote-api/secrets)
を参照してください。

## 本番環境での運用

本番環境では：
- 環境変数やシークレット管理サービスの利用を推奨します
- シークレットを git にコミットしないでください
- 鍵は定期的にローテーションしてください
